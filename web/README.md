# twog — site + dashboard

Self-contained, no-build, light/clean. Open directly or host as static files.

- `index.html` — one-pager: agentic primitives, real proof points, the loop, the flywheel.
  Motion: animated agentic-loop hero (canvas), scroll reveals, metric count-ups.
- `dashboard.html` — research-state mission control: lanes, evidence (proof capsules),
  the live H1 cross-species run, the flywheel artifacts.

**View locally:** open `web/index.html` in a browser (or `python -m http.server` in `web/`).
**Ship:** drop `web/` on any static host (GitHub Pages / Vercel / Netlify) — no build step.
Aesthetic + copy are intentionally swappable: wordmark is `twog`; accent is `--accent` (one var).
